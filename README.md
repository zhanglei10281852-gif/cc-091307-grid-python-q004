# 小区燃气隐患闭环

该项目服务于网格员和社区管理工作，负责小区燃气隐患闭环相关信息的规范化处理与留痕。

运行环境：Python 3.11（仅标准库）。代码位于 `src` 目录，配置与数据文件应按部署环境提供。

## 业务流程

主流程：**发现 → 派发 → 上门 → 复核 → 销项**，由状态机强约束推进；

- 登记隐患时需录入住户授权范围、设备状态、检查项目与整改期限；
- 三个异常分支均须留下说明：住户拒绝入户、设备更换、超过整改期限（延期/升级督办）；
- 只有复核通过才能销项；复核不通过退回重新整改，每次复核证据均留痕；
- 重复派发（同一请求号或流程进行中）返回原流程，不产生重复工单。

## 并发与离线

- 所有写操作携带 `expected_version` 做乐观并发控制，多人同时更新同一隐患时后写者收到 `VersionConflictError`；
- 离线终端补传（`apply_offline_event`）：同一事件幂等去重；隐患已销项或已有更新复核结论时，补传仅留痕不生效，不得覆盖已完成结论；
- 数据落盘 SQLite（`GasHazardService("data/hazards.db")`），服务重启后未完事项按原期限继续计时。

## 权限视图

- 网格员：仅可见所辖楼栋的必要信息（状态、期限、逾期天数、检查项目、设备概要、授权开关），不含住户姓名电话与复核证据；
- 管理者：完整档案，可追踪责任人、逾期天数、每次复核证据与全部事件留痕。

## 模块

| 文件 | 职责 |
| --- | --- |
| `src/service.py` | 领域服务入口 `GasHazardService`（流程、分支、补传、权限视图） |
| `src/models.py` | 状态机、分支枚举与登记数据结构 |
| `src/store.py` | SQLite 持久化与版本 CAS 更新 |
| `src/errors.py` | 领域异常 |
